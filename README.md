# juchao — 巨潮资讯网公告全量采集库

通过自建的 [PageSift](https://github.com/YOLOW92/pagesift) 服务（Firecrawl 兼容 API）抓取的**巨潮资讯网**（cninfo.com.cn）公告数据集。

## 数据规模

| 项目 | 数量 |
|---|---|
| **公告元数据（全量）** | **7,927,155 条**（2003-01-01 ~ 2026-10-24 全历史，深沪京市场） |
| PDF 原文样本 | 600 个（`pdf/`） |
| Markdown 正文样本 | 4,578 篇（`markdown/`，PageSift PDF→Markdown） |

分年统计（条）：2003: 34,594 ｜ 2004: 43,228 ｜ 2005: 56,420 ｜ 2006: 78,916 ｜ 2007: 93,537 ｜ 2008: 99,526 ｜ 2009: 96,701 ｜ 2010: 133,684 ｜ 2011: 164,344 ｜ 2012: 195,905 ｜ 2013: 217,207 ｜ 2014: 275,870 ｜ 2015: 366,106 ｜ 2016: 395,737 ｜ 2017: 443,012 ｜ 2018: 478,839 ｜ 2019: 477,816 ｜ 2020: 536,025 ｜ 2021: 587,950 ｜ 2022: 637,949 ｜ 2023: 663,733 ｜ 2024: 632,411 ｜ 2025: 718,901 ｜ 2026(至今): 498,744

## 目录结构

```
├── markdown/              # 公告正文 Markdown 样本（PageSift PDF→Markdown，每篇带元信息头）
├── pdf/                   # 公告 PDF 原文样本
├── full-meta/             # 全量采集数据
│   ├── csv/               # 全量公告索引（96 个按季度分片 CSV：ID/日期/代码/简称/标题/PDF链接，共 1.5GB）
│   ├── merge_stats.json   # 合并统计（分年条数）
│   └── crawl_stats.json   # 爬取统计（页数/重试/拆分等）
└── scripts/               # 抓取与转换脚本
    ├── fetch_announcements.py    # 小批量元数据抓取（日期窗口）
    ├── fetch_full_meta.py        # 全量元数据爬虫（四层递归分区 + 自适应限速 + 断点续跑）
    ├── download_pdfs.py          # 下载 PDF 原文
    ├── convert_to_markdown.py    # 调用 PageSift 转 Markdown
    ├── harvest_content.py        # 内容采集器（跟随爬虫输出并行转 Markdown）
    ├── merge_full_meta.py        # 合并去重 → JSONL + 分年 CSV
    └── watchdog_crawl.py         # 看门狗（API 解封后自动重启爬虫）
```

## 数据来源

- 入口页面：<https://www.cninfo.com.cn/new/index.jsp>
- 公告查询 API：`POST https://www.cninfo.com.cn/new/hisAnnouncement/query`
- PDF 原文：`https://static.cninfo.com.cn/finalpage/...`

## 全量采集方法（20.7 小时，275,459 次请求）

1. **分区体系**（峰值日 2025-04-29 单日 29,430 条验证，分区求和 == 总量）：
   日期 → 板块(5: 深主板/创业板/沪主板/科创板/北交所) → 行业(19 个证监会门类) → 分类(26 个市场分类)
2. **API 限制与对策**：pageSize 硬顶 30；单查询约 3,030 条后深分页冻结（四层分区压到上限以下）；实时插入导致 offset 漂移（每日窗口 + 不完整单元格重试，绝不存档残次数据）；突发流量 403 限流（自适应限速 8→20 rps、分级暂停 60s 翻倍至 20min、看门狗自动等解封重启）
3. **质量校验**：分年抓取量与 API 独立探测总量逐年级核对，误差 <0.1%（差异来自最后数日实时新增公告与 32 个峰值日 partial 单元格）
