# 恒大地产股份有限公司

# 关于法人股股权转让的公告

本公司及董事会全体成员保证公告内容的真实、准确和完整，对公告的虚假记载、误导性陈述或者重大遗漏负连带性责任。

根据《中华人民共和国证券法》、《股票发行与交易管理暂行条例》和《深圳证券交易所股票上市规则》等有关规定，中国农业银行海口市金贸区支行将其所持有的本公司的法人股全部转让给海南汉氏环境投资有限公司，现就有关事宜公告如下：

一、本公司接到中国农业银行海口市金贸区支行和海南汉氏环境投资有限公司关于签订本公司法人股转让协议，农行海口市金贸区支行以协议方式将其所持有的本公司的法人股 25,449,550 股，占总股本的 16.35％，全部转让给海南汉氏环境投资有限公司，转让价格为人民币 37,500,000 元。

二、本次转让过户完成后，海南汉氏环境投资有限公司持有本公司法人股 425,449,550 股，占总股本的 16.35％，成为本公司第二大股东。

三、本次转让完成后，本公司的总股本未发生变化，转让前后前十名股东情况变化如下：
