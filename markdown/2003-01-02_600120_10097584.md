# 浙江东方集团股份有限公司《关联交易管理办法》修正案

原：三 3（3）公司董事会审议关联交易时,该关联交易是与董事个人利益有关或董事个人在关联企业任职或拥有控股权,相关的董事不得参与对该关联交易事项的表决；

（4）公司股东大会就关联交易事项进行表决时,关联股东不得参加表决。关联股东因特殊情况无法回避时,在公司征得证券监管部门同意后,可以参加表决,但公司应当在股东大会决议中做出详细说明,同时对非关联方的股东投票情况进行专门统计,并在决议公告中予以披露。

修改为：

三 3（3）董事个人或者其所在任职的其他企业直接或者间接与公司已有的或者计划中的合同、交易、安排有关联关系时（聘任合同除外），不论有关事项在一般情况下是否需要董事会批准同意，均应当尽快向董事会披露其关联关系的性质和程度。

董事会审议关联交易事项时，关联董事应当回避，不参与投票表决。如关联董事回避表决造成参与表决的董事人数低于董事总数的 1/，2致使无法形成董事会决议时，在征得其他非关联董事同意，并承诺公平、公正、公允地审议关联交易事项后，关联董事可以按正常程序进行表决，并在董事会决议公告中作出说明。

（4）公司股东大会就关联交易事项进行表决时,关联股东不得参加表决，其所代表的有表决权的股份数不计入有效表决总数；股东大会决议的公告应当充分披露非关联股东的表决情况。
