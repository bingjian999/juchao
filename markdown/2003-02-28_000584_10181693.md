# 关于修订《成都蜀都大厦股份有限公司章程》的说明

根据中国证监会《上市公司治理准则》的要求和《上市公司章程指引》的具体规定，对公司章程进行了修订，现提交董事会审议。修改要点如下：

一、《章程》第三条增加“200年14月 10日公司共计 3517万.股8STA系Q统法人股在深圳证券交易所上市”。根据中国证券监督管理委员会证监公司字（200）015号0批文。

二、《章程》第六条注册资本由 18385.万0元0变7更5为：20，223，5080.元1。9 三、《章程》第二十条原股本结构将国家股、境内法人股及社会公众股分列，新章程中，将国家股与法人股合并列出。

《章程》第四章“股东和股东大会”中第一节“股东”共增加 8项条款，补充了第三十七条。

四、《章程》第三十七条，增加“董事、监事、经理执行职务时违反法律，行政法规或者公司章程的规定，给公司造成损害的，应承担赔偿责任，股东有权要求公司依法提起要求赔偿的诉讼”。根据最高人民法院司法解释订立此条款。

五、《章程》第四十条，增加“控股股东对上市公司及其他股东负有诚信义务”。六、《章程》第四十一条，增加“控股股东对上市公司董事、监事候选人的提名，应严格遵循法律、法规和本章程规定的条件和程序”。

七、《章程》四十二条，增加“控股股东不得直接或间接干预公司的决策及依法开展的生产经营活动，损害公司及其他股东的权益”。

八、《章程》四十三条，增加“控股股东与公司实行人员、资产、财务分开，机构、业务独立，各自独立核算、独立承担责任和风险”。

九、《章程》四十四条增加“公司人员应独立于控股股东，公司的经理人员、财务负责人、营销负责人和董事会秘书在控股股东不得担任除董事以外的其他职务”。

十、《章程》四十五条，增加“控股股东投入上市公司的资产应独立完整、权属清晰。控股股东不得占用、支配公司资产或干预公司对资产的经营管理”。

十一、《章程》四十六条，增加“控股股东不得以任何形式干预公司董事会、监事会及其他内部机构的独立运作，不得干预公司的财务、会计活动”。

十二、《章程》四十七条，增加“公司业务应完全独立于控股股东。控股股东及其下属的其他单位不应从事与公司相同或相近的业务，控股股东应采取有效措施避免同业竞争”。

在《章程》第四章“股东和股东大会”第二节“股东大会”中有如下改动：十三、《章程》五十一条 第（一）由“董事人数少于八人时”改为“董事人数不足《公司法》规定的最低人数，或者少于章程所定董事会人数的三分之二时”。第（二）增加“独立董事人数少于章程所定董事会人数三分之一时”

十四、《章程》六十二条 增加（三）“对于股东要求召开股东大会的书面提案，董事会应当依据法律、法规和公司章程决定是否召开股东大会。董事会决议应当在收到前述书面提议后十五日内反馈给股东并报告中国证券监督管理委员会派出机构和深圳证券交易所。董事会做出同意召开股东大会决定的，应当发出召开股东大会的通知；董事会认为股东的提案违反法律、法规和公司章程的规定，应当做出不同意召开股东大会的决定，并将反馈意见通知股东。股东可在收到董事会通知之日起十五日内决定放弃召开临时股东大会，或者自行发出召开临时股东大会的通知。股东决定自行召开临时股东大会的，应当书面通知董事会，在报告中国证券监督管理委员会派出机构和深圳证券交易所备案后，发出召开临时股东大会的通知，召集的程序应当尽可能与董事会召集股东大会的程序相同”。

十五、《章程》六十四条，将原“董事会人数少于八人或者公司未弥补亏损额达到股本总额三分之一”更改为“董事会人数不足《公司法》规定的法定最低人数，或者少于章程规定人数的三分之二，或者公司未弥补亏损额达到股本总额的三分之一”。

在《章程》第四章中第三节“股东大会提案”中增加了三项条款。

十六、《章程》六十六条，增加“董事会在召开股东大会的通知中应列出本次股东大会讨论的事项，并将董事会提出的所有提案内容充分披露”。

十七、《章程》六十七条，增加“会议通知发出后，董事会不得再提出会议通知中未列出事项的新提案，对原有提案的修改应当在股东大会召开十五日前公告。否则，会议召开日期应至少顺延十五日”。

十八、《章程》六十八条 增加“公司召开股东大会，持有或者合并持有公司”发行在外有表决权股份总数百分之五以上的股东,有权向公司提出新的提案。

在<章程>第四章“股东和股东大会”第四节“股东大会决议”中，有增加条款。十九、《章程》七十二条，增加“如控股股东持有表决权的股份超过公司股份总数的百分之三十，则股东大会选举董事时应按本章程第九十二条的规定用累积投票制进行表决。

二十、《章程》七十四条（三）中将董事会成员的责任保险列入普通决议通过。二十一、《章程》九十条，增加“董事会和具备股东大会提案权的公司股东有权提名董事候选人，股东提名董事候选人的程序参照本章程规定的股东大会提案程序办理”。

二十二、《章程》九十一条，增加“公司应在股东大会召开前披露董事候选人的详细资料。董事候选人应在股东大会召开之前做出书面承诺，同意接受提名，承诺公开披露的董事候选人的资料真实、完整，并保证当选后切实履行董事职责”。

二十三、《章程》九十二条，增加“控股股东持有表决权的股份数超过公司股份总数的百分之三十时，董事的选举应采用累积投票制，即每一股东可依其持有的表决权的股份乘以全部待选董事人数所累积的票数投给一个董事候选人或分别投给多个董事候选人，各董事候选人按所得票数从高到低排列，得票数靠前者当选。

如董事候选人得票数相同且待选董事仍有缺额，则应继续采取累积投票制对得票数相同的候选人进行新一轮选举，直到当选董事人数达到全部待选董事名额。

二十四、《章程》九十三条，增加“公司应和董事签订聘任合同，明确公司和董事之间的权利义务、董事的任期、董事违反法律法规和公司章程的责任以及公司因故提前解除合同的补偿等内容”。

二十五、《章程》第五章第三节“董事会”行使职权中有增加及修改条款：原章程九十七条规定董事会有权确定公司净资产百分之十五以下的投资，章程一百一十九条（三）款中将该比例修改为百分之三十；（八）款中增加“在公司净资产百分之三十的限额内，决定公司的风险投资、资产抵押及其他担保事项”。

在《章程》第五章“董事会”中增加第二节“独立董事”，对独立董事任职资格及权利、义务做出详尽的规定，增加第四节“董事会专门委员会”。

在《章程》中增加第十二章“信息披露”的条款。
