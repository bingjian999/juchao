| \| \| \| \| --- \| --- \| \| ![](https://static.cninfo.com.cn/images/jjjj1.gif) \| \| \| \| \| \| **百科药业：2003年第一次临时股东大会决议公告** 2003-03-01 06:40 证券代码：000627 证券简称：百科药业 公告编号：2003-007号 湖北百科药业股份有限公司 2003年第一次临时股东大会决议公告 本公司及董事会全体成员保证公告内容的真实、准确和完整，对公告的虚假记载、误导 性陈述或者重大遗漏负连带责任。 一、会议召开和出席情况 公司2003年第一次临时股东大会于2003年2月28日上午在湖北省荆门市国际大酒店召开， 与会股东及股东代理人共4人，代表股份299,490,306 股，占公司总股份的50.36% ，本次大会对提案二和提案三中选举董事的表决采用了累积投票制，符合《公司法》和《公司 章程》的规定。公司部分董事、监事及高级管理人员列席了会议。董事长向汉林先生因公委托 董事金志好先生主持会议。 二、提案审议情况 1、审议通过了《关于修改公司章程部分条款及授权董事会办理工商登记变更的议案》； 根据中国证监会发布的《上市公司章程指引》、《上市公司股东大会规范意见》、及公司 发展需要，为保证公司规范运作，结合公司实际，同意对公司章程部分条款作相应的修改并授 权董事会办理工商登记变更及其他相关手续。 原 第一百二十三条 董事会由七名董事组成，设董事长一人。 修改为 第一百二十三条 董事会由十一名董事组成，设董事长一人，副董事长一人。 同意票：299,490,306股，占到会股东代表股份的100 %； 反对票： 0 股；弃权票：0 股。 2、审议通过了《关于调整及增补董事会成员的议案》； 1、关于肖云华先生辞去公司董事职务的议案 同意票：299,490,306股，占到会股东代表股份的 100 %； 反对票：0 股；弃权票： 0 股。 2、关于增补刘益谦先生任公司董事的议案 同意票：299,490,306股，占到会股东代表股份的100 %； 反对票： 0 股；弃权票：0 股。 3、关于增补周令闻先生任公司董事的议案 同意票： 299,490,306 股，占到会股东代表股份的100 %； 反对票： 0 股；弃权票： 0 股。 4、关于增补匡正龙先生任公司董事的议案 同意票：299,490,306股，占到会股东代表股份的100 %； 反对票： 0 股；弃权票： 0 股。 （公司新任董事简历见2003年1月28日《中国证券报》或《证券时报》） 3、通过了《关于提名独立董事候选人的议案》。 1、关于增补胡建军先生任公司独立董事的议案 同意票：299,490,306股，占到会股东代表股份的100 %； 反对票： 0 股 ；弃权票：0 股。 2、关于增补谭焕珠先生任公司独立董事的议案 同意票：299,490,306股，占到会股东代表股份的100%； 反对票： 0 股 ；弃权票： 0 股。 （独立董事简历见2003年1月28日《中国证券报》或《证券时报》，两位独立董事的任职 资格和独立性的有关材料已经上报中国证监会武汉证券监督管理办公室审核通过。） 三、律师出具的法律意见 公司聘请了湖北正信律师事务所乐瑞、高英律师现场见证了本次股东大会，并就本次股东 大会出具了《法律意见书》。该法律意见书认为：公司本次股东大会的召集、召开程序符合相 关法律法规及《公司章程》的规定，出席会议人员资格合法有效，股东大会的表决程序、通过 的决议内容均合法有效。 四、备查文件 1、《湖北正信律师事务所关于湖北百科药业股份有限公司2003年第一次临时股东大会的 法律意见书》 2、《湖北百科药业股份有限公司第二届董事会二十九次会议决议》 3、《湖北百科药业股份有限公司2003年第一次临时股东大会决议》 特此公告。 湖北百科药业股份有限公司 2003年2月28日 ![](https://static.cninfo.com.cn/images/icolumn_arrow.gif) 关闭窗口 \| \| \| ![](https://static.cninfo.com.cn/images/jjjj3.gif) \| 相关信息 \| \| --- \| --- \| \| \| \| \| \| \| |  |
