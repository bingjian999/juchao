# 大连铁龙实业股份有限公司 200年2年度报告补充公告

根据上海证券交易所对本公司 2002 年年度报告的事后审核意见，现就以下四个问题进行了补充说明，详细内容请见上海证券交易所网站 www.sse.com.cn。

一、200年2度母公司主营业务收入和成本较上年度大幅度下降的原因（详见本公司 2020年度报告第七节董事会报告中的报告期经营情况）。

二、公司董事、监事报酬的决策程序和确定依据（详见本公司 200年2度报告第四节董事、监事、高级管理人员和员工情况）。

三、报告期内公司按行业、产品、地区说明主营业务收入、主营业务利润的构成情况（详见本公司 200年2度报告第七节董事会报告中的报告期经营情况）。

四、公司客运业务清算收入关联交易的依据及定价原则（详见本公司 200年2度报告第九节重要事项中的报告期内的重大关联交易事项）。
