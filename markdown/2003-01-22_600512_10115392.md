会议文件之二投票表决办法

# 200年3第一次临时股东大会投票表决办法

一、 各项议案的通过，由股东或股东代表以记名方式分别表决。二、 每一表决表分别注明该票所代表的股份数，每股为一票表决权，投票结果按股份数判定票数。

三、 会议设监票人三名，其中两名为股东代表，一名为监事代表；由监票人计票并当场宣布表决结果。

四、 表决时，在表决票相应的空格栏里“赞成”用“√”表示； “反对”用“×”表示；弃权用“○”表示；不填作弃权处理。

五、 不使用本次会议统一发放的表决票，或夹写规定外文字或填写模糊无法辨认者，视为无效票，作弃权处理。

六、 在会议期间离场或不参与投票者，作弃权处理。

七、 本次股东大会审议的第一、二、三项事项（其中第三项事项应分别对议案及分项列示的内容进行表决）需以特别决议方式通过，即由出席会议的股东或股东代表所持表决权的三分之二以上通过；第四、五项事项以一般决议方式通过，即由出席会议的股东或股东代表所持表决权的二分之一以上通过。

会议文件之三第一号议案

# 关于变更公司注册资本的议案

各位股东及股东代表：

经中国证券监督管理委员会证监发行字[2002号]文1核2准6，公司于 200年212月 11日成功向社会公众公开发行人民币普通股（A）股股票 600万0股。本次发行股票面值为 1元，发行价为每股人民币 5.0元0，上述发行募集资金已经入帐并经浙江天健会计师事务所验资。公司发行的 600万0股人民币普通股经上海证券交易所上证上字[2002号]文192 批准，已于 200年212月 26日在上海证券交易所上市流通。

本次公司 600万0股人民币普通股发行前，公司原注册资本为人民币 9973.万5元1，6公4开发行 600万0股股票后已增加至 15973.万5164 元；公司的股本总额也增加至 15973股5。1第6三4届董事会第四次会议决定根据上述情况相应变更公司注册资本。

根据有关法律、法规和规范性文件和公司《章程》的规定，公司本次增加注册资本应提请股东大会审议通过，并由股东大会授权董事会办理相应的工商变更登记手续。

以上议案，请各位股东及股东代表审议。

# 关于变更经营范围的议案

各位股东及股东代表：

根据建设部《关于公布第二批一级资质建筑业企业名单的公告》（200年21月 16日建设部公告 42号）和浙江省建设厅浙建建[2002]19 号文，公司按照建设部 200年17月 1日起施行的《建筑业企业资质管理规定》进行申报，取得了市政公用工程施工总承包壹级，公路工程施工总承包壹级，公路路面工程专业承包壹级，公路路基工程专业承包壹级，房屋建筑工程施工总承包贰级，建筑装修装饰工程专业承包贰级，桥梁工程专业承包贰级。

公司现行营业执照上的经营范围：“市政工程建筑（资质壹级）、公路工程施工（二级）”与上述资质已不相符，应予变更。第三届董事会第四次会议建议公司经营范围变更为：“市政工程、公路工程、桥梁工程、房屋建筑工程、建筑装修装饰工程。”

根据有关法律、法规和规范性文件和公司《章程》的规定，公司本次变更经营范围应提请股东大会审议通过，并由股东大会授权董事会办理相应的工商变更登记手续。

以上议案，请各位股东及股东代表审议。

腾达建设集团股份有限公司董 事 会

# 关于修改公司章程的议案

各位股东及股东代表：

根据《关于变更公司注册资本的议案》，公司原注册资本为人民币 9973.万5元1，6公4开发行 600万0股股票后已增加至 15793.万5元1；64 公司的股本总额也增加至 15793股5。164

根据《关于变更公司经营范围的议案》，公司经营范围拟变更为：“市政工程、公路工程、房屋建筑工程、建筑装修装饰工程、桥梁工程。”

根据公司第三届董事会第四次会议决议，考虑到独立董事人选问题以及提高董事会工作效率，建议公司董事会由九名董事组成，其中独立董事三人。

根据有关法律、法规和规范性文件的规定，公司在增加注册资本、调整股本总额、变更经营范围、确定董事名额，应当对章程作相应的修改；同时鉴于公司为在 200年2度申请首次向社会公众公开发行股票，已于 200年110月 18日召开的 200年1度第一次临时股东大会中通过了《腾达建设集团股份有限公司章程（草案）》并向中国证监会报备，董事会决定以该章程草案为基础，并根据公司的实际情况对公司章程的相关条款作如下修正。

# 关于制定《腾达建设集团股份有限公司

# 治理纲要》的议案

各位股东及股东代表：

为了进一步完善公司的法人治理结构，规范公司运作，保护公司投资者尤其是中小投资者的利益，满足公司长远发展的需要，公司第三届董事会第三次会议根据中国证监会《上市公司治理准则》的要求，通过了《腾达建设集团股份有限公司治理纲要（草案）》。

公司治理纲要草案对平等对待所有股东、保护股东利益；强化董事诚信勤勉义务、规范董事会运作；发挥监事会监督作用；建立健全绩效评价和激励约束机制；保障利益相关者合法权利；强化信息披露、提高公司透明度等方面均作了大量的和细致的规定，是今后一个时期提高公司治理水平的重要指导性文件。

根据有关法律、法规、规范性文件和公司《章程》的规定，《腾达建设集团股份有限公司治理纲要（草案）》应提请股东大会审议通过，故第三届董事会第四次会议特向本次股东大会提出本议案。

以上议案，请各位股东及股东代表审议。

会议文件之七第五号议案

# 关于制定《腾达建设集团股份有限公司独立董事制度的议案》

各位股东及股东代表：

为了进一步完善公司的法人治理结构，规范公司运作，充分发挥独立董事的作用，保护公司投资者尤其是中小投资者的利益，公司第三届董事会第三次会议按照中国证券监督管理委员会证监发[2001号]102 《关于在上市公司建立独立董事制度的指导意见》的要求，拟定了《腾达建设集团股份有限公司独立董事制度（草案）》。

《独立董事制度（草案》》对独立董事的独立性要求、任职资格、提名选举与更换、职权、就重大事项发表独立意见等作了全面系统的规定，是贯彻落实《关于在上市公司建立独立董事制度的指导意见》和指导公司建立健全独立董事制度的重要法律文件，对完善公司的法人治理结构，规范公司运作将发挥积极的作用。

根据有关法律、法规、规范性文件和公司《章程》的规定，《腾达建设集团股份有限公司独立董事制度（草案）》应提请股东大会审议通过，故第三届董事会第四次会议特向本次股东大会提出本议案。

以上议案，请各位股东及股东代表审议。

腾 达 建设集团股份有限公司董 事 会
