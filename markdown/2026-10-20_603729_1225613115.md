# 上海龙韵文创科技集团股份有限公司第六届董事会第三十四次会议决议公告

本公司董事会及全体董事保证本公告内容不存在任何虚假记载、误导性陈述或者重大遗漏，并对其内容的真实性、准确性和完整性承担法律责任。

一、董事会会议召开情况

上海龙韵文创科技集团股份有限公司（以下简称“公司”）第六届董事会第三十四次会议（以下简称“会议”）于 2026 年 10 月 20 日在公司（上海浦东民生路 118 号滨江万科中心 16 层）会议室以现场和通讯相结合的方式召开。

应到董事 5 人，实到董事 5 人，公司部分高管人员列席了本次会议。本次会议的召集、召开以及参与会议董事人数符合《公司法》等有关法律、法规及《公司章程》的规定。

二、董事会会议审议情况

经参加会议董事认真审议并经记名投票方式表决，做出如下决议：（一）审议通过《关于公司董事会换届选举及提名董事候选人的议案》

公司第六届董事会将于 2026 年 11 月 5 日届满，经公司董事会提名委员会提名，并经本次会议审议通过，提名段佩璋先生、余亦坤先生、周衍伟先生为公司第七届董事会非独立董事候选人，提名甘胜军先生、李国民先生为公司第七届董事会独立董事候选人（简历请见附件）。

表决情况：

1.1《关于提名段佩璋先生为公司第七届董事会非独立董事候选人的议案》表决结果：赞成 5 票，反对 0 票，弃权 0 票 1.2《关于提名余亦坤先生为公司第七届董事会非独立董事候选人的议案》表决结果：赞成 5 票，反对 0 票，弃权 0 票 1.3《关于提名周衍伟先生为公司第七届董事会非独立董事候选人的议案》表决结果：赞成 5 票，反对 0 票，弃权 0 票 1.4《关于提名甘胜军先生为公司第七届董事会独立董事候选人的议案》表决结果：赞成 5 票，反对 0 票，弃权 0 票 1.5《关于提名李国民先生为公司第七届董事会独立董事候选人的议案》表决结果：赞成 5 票，反对 0 票，弃权 0 票提名为独立董事候选人的事项已经上海证券交易所备案、审核无异议。本议案尚需提交公司股东会审议。

（二）审议通过《2025 年第三季度报告》公司《2026 年第三季度报告》的编制程序符合法律、法规和中国证监会的有关规定，报告内容真实、准确、完整地反映了公司 2026 年第三季度经营的实际情况，不存在任何虚假记载、误导性陈述或者重大遗漏。

内容详见公司同日于上海证券交易所网站（www.sse.com.cn）披露的公司《2026 年第三季度报告》。

本议案提交董事会审议前，已经董事会审计委员会审议通过。

表决结果：赞成 5 票，反对 0 票，弃权 0 票

（三）审议通过《关于提请召开公司 2026 年第三次临时股东会的议案》

关于会议的时间、地点、议程和议题等具体事宜，公司将另行发出股东会的通知和股东大会资料。

表决结果：赞成 5 票，反对 0 票，弃权 0 票
