# 深圳市海王生物工程股份有限公司第二届董事局第十六次会议决议公告

本公司董事局及董事局全体成员保证公告内容的真实、准确和完整，对公告的虚假记载、误导性陈述或重大遗漏负个别及连带责任。

本公司董事局于 200年303月 11日召开第二届第十六次会议，应到董事 6名，实际出席会议的董事 6名，公司部分监事及高管人员列席了会议，会议的召开和表决程序符合《公司法》和《公司章程》的规定。会议由公司董事局主席张思民先生主持。会议认真学习和讨论了中国证券监督管理委员会深圳稽查局对公司的《稽查结果通知书》以及中国证监会深圳证券监管办公室下发的《关于对深圳市海王生物股份有限公司的监管建议书》，与会董事一致认为：中国证券监督管理委员会深圳稽查局对公司的调查及监管意见对于公司各方面的管理工作产生了积极的促进作用，董事局责成经营管理班子尽快就监管意见提出整改方案，报送董事局审议，并以此为动力进一步加强公司管理的规范化工作，提高公司管理水平，以更好的业绩回报广大股东。

本次董事局会议还审议通过了以下议案：

1、聘请刘占军先生为公司总经理（简历附后）；

2、聘请于琳女士为公司副总经理（简历附后）。

特此公告。

深圳市海王生物工程股份有限公司董事局 23年 0 03 月 1 2日附：

刘占军简历刘占军，男，45岁，经济学博士、管理学博士后，现任中国综合开发研究院(深圳) 秘书长助理、研究咨询部部长,曾主持和参与国家多项重点研究课题和企业咨询工作。200年06月至 200年29月任海王生物独立董事，200年29月至今任海王生物首席管理专家。

于琳简历于琳，女，46岁，硕士，毕业于中山大学分子生物学专业。197年4至 198年2，在广东省汕头市生化药厂工作，任质检员、药剂师；198年2至 199年3，在广东省商业厅科技处工作，正科级；199年3至 200年23月，任广东省生物化学制药行业协会秘书长；200年23月至今任海王生物技术中心负责人。
