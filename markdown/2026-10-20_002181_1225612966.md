# 广东广州日报传媒股份有限公司关于子公司对外投资进展的公告

本公司及董事会全体成员保证信息披露的内容真实、准确、完整，没有虚假记载、误导性陈述或重大遗漏。

一、投资概述广东广州日报传媒股份有限公司（以下简称“公司”）第八届董事会第十五次会议审议通过了《关于全资子公司拟投资参股“China Audience Network Inc.”的议案》，公司全资子公司广州日报新媒体有限公司（以下简称“新媒体公司”）以自有资金1600万美元认购China Audience Network Inc.新发行的65,879,582股D轮优先股，占发行后标的公司总股本的13.33%。具体内容详见公司于2015年2月5日在《中国证券报》《证券时报》《证券日报》及巨潮资讯网（http://www.cninfo.com.cn）刊登的《关于公司子公司认购China Audience Network Inc.优先股的公告》（2015-003）。

二、投资事项的进展情况根据新媒体公司与悠易科技（China Audience Network Inc.后改名为Yoyi Digital Inc.，以下简称“悠易科技”）2015年4月10日签署生效的《第六版章程与备忘录》，因悠易科技未能如期在D轮投资后5年内实现合格IPO上市，在2020年4月触发回购条款，但悠易科技无力回购。经谈判，新媒体公司与悠易科技相关公司分别于2021年和2022年签订关于回购延期的《协议》和《协议修订》，悠易科技支付额外款项以换取延期执行回购。通过两次回购延期，新媒体公司累计收到额外款项200万美元，按协议约定的汇率折合人民币1,321.19万元。根据约定，该款项的退还情形包括：“（i）公司（指悠易科技）根据第3.3条和/或章程第6(vi)(c)条发出初始赎回通知并完成首次赎回以及支付相关款项，或（ii）公司（指悠易科技）和股东（指新媒体公司）依据本协议第9条通过善意谈判并达成一致意见后，公司完成在公司董事会正式批准的证券交易所以包销形式首次公开发行其普通股（‘首次公开发行’）或视为清算事件（定义见公司章程及股东协议）发生”。

2022年10月26日第二次延期执行回购期限再次到期以来，新媒体公司多次向悠易科技发出回购函件，要求悠易科技书面答复回购安排。但悠易科技未提供可行的回购方案。

2026年9月，悠易科技拟出售主要资产，构成《第六版章程与备忘录》约定的“视为清算事件”，结合悠易科技汇报的近期情况及律所意见，鉴于悠易科技未执行回购约定，以悠易科技目前的经营情况IPO无望，且新媒体公司不会就前述视同清算事项与悠易科技达成一致意见，公司已决定对相关议案投反对票，综合研判，《协议》和《协议修订》中相关款项已不具备退还的条件。上述款项将计入当期损益。

三、对公司的影响情况及风险提示根据前述情况，该事项预计增加本年度净利润1321.19万元，具体会计处理及影响金额以会计师年度审计确认的结果为准。敬请投资者注意投资风险。
