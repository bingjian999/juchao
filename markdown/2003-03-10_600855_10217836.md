# 北京航天长峰股份有限公司关于完善薪酬体系的议案

各位董事：

为了充分调动公司中、高层管理人员的积极性，充分体现责、权、利相结合，按劳分配的原则，公司拟建立年薪考核制度，具体办法为：

1、年薪由基本工资（F1）及岗位考核工资（F2）两部分组成（比例为 7：3），基本工资按月发放，岗位工资部分年底根据岗位考核后发放。

2、实施岗位考核，对实行年薪制人员年底按岗位责任目标进行考核，确定受薪人的考核系数（Pi）。

3、公司年薪制人员的工资责任系数（Tj）为：

| 人员类别 | 高 管 |  |  |  | 分公司经理 |
| --- | --- | --- | --- | --- | --- |
|  | 董事长 | 总经理 | 副总、董秘、总经理助理财务总监 |  |  |
| 系数 Tj | 4.5 | 4 | 3.5 | 3 | 2.5 |

按月发放的基本工资为：F1=R*Tj*70%；年底考核发放的岗位工资 F2=12*R* Tj*Pi*30%（其中 R 为公司上一年度全体员工月工资的平均数）。

4、由董事会提名及薪酬考核委员会制定具体考核办法。

请各位董事审议，此项议案需经股东大会审议通过。

北京航天长峰股份有限公司董事会

2003 年 3 月 6 日
