# 广西红日股份有限公司关于调整公司董（监）事津贴的议案

鉴于公司董（监）事的岗位津贴标准偏低，董事会考虑从 2003 年开始适当增加董（监）事的岗位津贴，下列是修改后的津贴标准（每年按十三个月发放）。

| 职 务 | 专职津贴/月 | 非专职津贴/月 |
| --- | --- | --- |
| 董事长 | 3000 元 |  |
| 副董事长 | 2400 元 | 2000 元 |
| 董事 | 2000 元 | 1600 元 |
| 独立董事 |  | 2000 元 |
| 董事会秘书 | 2000 元 |  |
| 监事会主席 | 2000 元 |  |
| 监事 | 1000 元 | 800 元 |

本议案需提交 2002 年度股东大会审议表决。

广西红日股份有限公司董事会二○○三年三月十二日
